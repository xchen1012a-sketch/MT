# collector —— Windows MT5 采集器

**状态：占位，待 P1 采集可行性验证后实现。**

## 职责边界

- 在每台 Windows 电脑上统一管理已登记的多个 MT5 终端实例。
- 通过 MetaTrader5 官方 Python 接口**只读**采样：余额、净值、保证金、持仓、历史成交。
- 本地记录采样时间与上传状态，断网后保存已成功采集的数据，恢复后补传。
- **不实现任何交易执行接口**（下单、平仓、改单）。

## 候选架构（未经实测不算定型）

每个 MT5 终端路径对应一个独立采集子进程，由统一管理器负责发现、调度、重连与上报。
多开隔离的真实稳定性必须在 GTC 多开环境实测，结论写入 `docs/`。

## 依赖

- Python 3.11+
- `MetaTrader5` 官方包（仅 Windows）
- 仅从官方渠道获取，**不执行来源不明的二进制文件**

## P1 待验证

1. 官方 SDK 能否稳定连接指定终端路径的多实例。
2. 不同安装目录 / 数据目录下的行为差异。
3. 账户切换、终端关闭、Windows 休眠时的状态识别。
4. SDK 路线不通时，评估 MQL5 EA + 本地代理的备选路径。

## 安全要求

- 最小权限运行。
- MT5 凭据尽量留在 Windows 安全存储，**不上传交易密码**。
- 面板用户认证与设备认证分离，设备支持暂停、撤销与密钥轮换。
